# MediPlus Client 🏥

**MediPlus Client** is a cutting-edge medical and healthcare web application frontend, engineered for high performance and scalability. Built with the latest **Next.js 16** and **React 19**, it leverages a modern architecture to provide a seamless user and developer experience.

---

## 🚀 Tech Stack

### Core

- **Framework:** Next.js 16 (App Router)
- **Library:** React 19
- **Language:** TypeScript

### UI & Styling

- **Styling:** Tailwind CSS v4
- **Components:** shadcn/ui (Radix UI)
- **Icons:** Lucide Icons
- **Animations:** Framer Motion
- **Notifications:** Sonner (Toast)

### State & Data Management

- **Global State:** Redux Toolkit & React Redux
- **Server State:** TanStack React Query (v5)
- **HTTP Client:** Axios

### Forms & Validation

- **Form Library:** React Hook Form
- **Validation:** Zod
- **Resolver:** @hookform/resolvers

### Utilities

- **Auth:** JWT Decode & js-cookie
- **Dates:** date-fns
- **Helper Functions:** lodash

## 📁 Project Scripts

Use these commands to manage the project:

| Command         | Description                          |
| :-------------- | :----------------------------------- |
| `npm run dev`   | Runs the app in development mode     |
| `npm run build` | Builds the app for production        |
| `npm run start` | Starts the production server         |

## 🛠 Getting Started

### Prerequisites

Ensure you have **Node.js** (v20.x or higher recommended) and **npm** installed.

### Installation

1. Clone the repository:

   ```bash
   git clone [https://github.com/your-username/mediplus-client.git](https://github.com/your-username/mediplus-client.git)

   ```

   2.Navigate to the project director:

```bash
cd mediplus-client
```

3.Install dependencies:

```bash
npm install

```

(or yarn install if using Yarn Or pnpm Or bun)
